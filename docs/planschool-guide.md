# PLANSCHOOL 사용 설명서

> 작성용 초안입니다. `[캡처]` 로 표시된 자리에 스크린샷을 넣고, 문구는 자유롭게 다듬어 쓰세요.
> 이미지는 `docs/images/` 에 넣고 `![설명](./images/파일명.png)` 형식으로 삽입하면 됩니다.

---

## 1. PLANSCHOOL이란

선생님을 위한 대시보드형 배경화면입니다. 시간표, 급식, 학사일정, 할 일, 쪽지를 한 화면에서 확인할 수 있습니다.

- 웹 브라우저에서 바로 사용할 수 있습니다.
- **Lively Wallpaper** 같은 프로그램에 주소를 등록하면 바탕화면 자체를 PLANSCHOOL로 쓸 수 있습니다.
- 가로 모니터와 세로 모니터 레이아웃을 모두 지원합니다.

`[캡처 1] 대시보드 전체 화면`

### 처음 접속하면

- 로그인하지 않아도 시계와 폴더는 보이지만, **시간표·할 일·급식·학사일정·쪽지함은 로그인해야 사용할 수 있습니다.**
- 날씨 위젯은 **위치 권한**을 허용해야 표시됩니다.

## 2. 회원가입과 로그인

### 회원가입

`[캡처] 회원가입 화면`

입력 항목은 다음과 같습니다.

| 항목 | 설명 |
|---|---|
| 이메일 | 로그인 아이디로 사용됩니다 |
| 비밀번호 | 6자 이상 |
| 이름 | 대시보드에 "○○○ 선생님"으로 표시됩니다 |
| 소속 교육청 | 선택하면 학교 검색이 열립니다 |
| 학교 | 이름을 검색해 목록에서 선택 |
| 생일 | 생일 당일 대시보드에 축하 화면이 뜹니다 |

가입 후 **이메일 인증**을 완료해야 로그인할 수 있습니다. 메일이 오지 않으면 스팸함을 확인해 주세요.

### 로그인

`[캡처] 로그인 화면`

- **로그인 유지**를 켜두면 다음 접속 때 자동으로 로그인됩니다. 배경화면으로 쓸 때는 켜두는 것을 권장합니다.
- 아이디가 기억나지 않으면 **아이디 찾기**, 비밀번호는 **비밀번호 찾기**에서 재설정 메일을 받을 수 있습니다.

## 3. 처음 한 번은 꼭 해주세요

이 두 가지를 설정해야 나머지 기능이 제대로 동작합니다.

### 3-1. 학교 정보 등록

**설정 → 계정 → 프로필 수정**

`[캡처 4] 설정 → 프로필 수정`

1. 소속 교육청을 선택합니다.
2. 학교 이름을 검색해 목록에서 선택합니다.
3. 저장을 누릅니다.

> 학교를 설정하지 않으면 **급식 정보**와 **학사일정** 위젯에 "학교 정보를 설정해주세요"만 표시됩니다.

**담임 학급** 칸에 `3-5` 처럼 입력하면 담임 선생님용 기능이 켜집니다.

- 시간표에 **'학급 시간표' 탭**이 추가됩니다.
- '지금 이 시각' 위젯에 우리 반 현재 수업이 함께 표시됩니다.
- 비워두면 이 기능은 나타나지 않습니다.

### 3-2. 교시 시간 맞추기

**설정 → 학교·일정 → 교시 시간**

`[캡처 5] 설정 → 교시 시간`

학교 일과에 맞게 교시 이름과 시작·종료 시각을 조정합니다. 여기서 설정한 값이 시간표의 행 구성, '지금 이 시각' 위젯의 현재 교시 판단, 퇴근까지 남은 시간 계산의 기준이 됩니다.

기본값은 다음과 같습니다.

| 교시 | 시작 | 종료 | 기본 사용 |
|---|---|---|---|
| 1교시 | 08:20 | 09:10 | 사용 |
| 2교시 | 09:20 | 10:10 | 사용 |
| 3교시 | 10:20 | 11:10 | 사용 |
| 4교시 | 11:20 | 12:10 | 사용 |
| 점심시간 | 12:10 | 13:00 | 사용 |
| 5교시 | 13:00 | 13:50 | 사용 |
| 6교시 | 14:00 | 14:50 | 사용 |
| 7교시 | 15:00 | 15:50 | 사용 |
| 방과후 A | 16:30 | 17:20 | 사용 안 함 |
| 방과후 B | 18:20 | 20:00 | 사용 안 함 |

- 교시 이름은 자유롭게 바꿀 수 있습니다. (예: "방과후 A" → "돌봄")
- 사용하지 않는 교시는 꺼두면 시간표에서 행이 사라집니다.

### 3-3. 기본 퇴근 시각

같은 화면(**설정 → 교시 시간**) 아래쪽에서 **기본 퇴근 시각**을 정할 수 있습니다.

'지금 이 시각' 위젯의 "오늘 퇴근까지 ○시간 ○분 남았어요"가 이 시각을 기준으로 계산됩니다. 기본값은 **16:00**입니다.

- 방과후 수업이 있는 날은 그 수업이 끝나는 시각까지 자동으로 늘어납니다.
- 저장하면 대시보드에 바로 반영됩니다.

## 4. 위젯 사용법

### 프로필

이름, 이메일, 그리고 아래쪽에 **퀵링크 바**가 있습니다.

- 기본 퀵링크: 나이스 / 에듀파인 / 클래스룸
- 링크를 누르면 새 창으로 열립니다.
- 맨 오른쪽 **설정** 버튼으로 설정 페이지에 들어갑니다.
- 오른쪽 위 **로그아웃**

### 폴더

자주 쓰는 분류 이름 3개를 표시합니다. 기본값은 "진행중인 업무 / 나중에 볼 파일 / 기타"이며 **설정 → 기타 → 폴더 이름**에서 바꿀 수 있습니다.

### 시계

현재 시각과 오늘 날짜·요일을 표시합니다.

### 날씨

현재 기온, 최저·최고 기온, 지역명, 날씨 아이콘을 보여줍니다.

> "위치 권한이 필요합니다"가 뜨면 브라우저에서 위치 접근을 허용해 주세요.

### 쪽지함 버튼

동그란 프로필 사진 모양의 버튼입니다. 누르면 쪽지함으로 이동하고, 안 읽은 쪽지가 있으면 **빨간 숫자 뱃지**가 표시됩니다.

### 시간표

`[캡처] 시간표 위젯`

**과목 입력하기**

1. 원하는 칸을 **더블클릭**합니다.
2. 과목명, 교실을 입력하고 색상을 고릅니다.
3. 연강이면 몇 교시까지인지 지정해 칸을 합칠 수 있습니다.

`[캡처 3] 시간표 셀 편집 팝업`

과목명을 지우고 저장하면 해당 칸이 비워집니다.

**이번주만 임시로 바꾸기**

- 오른쪽 위 **'이번주 편집'** 버튼을 누릅니다.
- 칸 하나를 클릭해 선택하고, 다른 칸을 클릭하면 두 칸이 **교환**됩니다.
- **월요일이 되면 자동으로 원래 시간표로 돌아옵니다.** 원래대로 되돌리려면 '초기화'를 누르세요.
- 교과 전담 수업이 바뀌었을 때 원본을 건드리지 않고 쓰기 좋습니다.

**학급 시간표 탭**

담임 학급을 입력한 경우에만 나타납니다. 내 시간표와 별개로 우리 반 시간표를 관리할 수 있습니다.

### 지금 이 시각

지금이 몇 교시이고 무슨 수업인지, 퇴근까지 얼마나 남았는지 알려줍니다.

| 상황 | 표시 |
|---|---|
| 수업 중 | `3교시 수학 (과학실)` |
| 빈 시간 | `3교시 공강` |
| 쉬는 시간 / 점심 / 석식 | `쉬는 시간`, `점심시간`, `석식시간` |
| 수업 시작 전 | `오늘 하루도 화이팅!` |
| 일과 종료 후 | `얼른 퇴근하세요!` |
| 주말 | `오늘은 쉬는 날` |

- 아래 진행 바는 오늘 일과의 진행 정도입니다.
- 퇴근 시각은 **설정 → 교시 시간 → 기본 퇴근 시각**에서 바꿀 수 있습니다. (기본 16:00)
- 방과후 교시를 켜두었고 그 시간에 수업이 있으면 그 수업이 끝나는 시각까지로 늘어납니다.
- 담임 학급을 설정했다면 우리 반 현재 수업도 함께 표시됩니다.

### 할 일

`[캡처] 할 일 위젯`

| 동작 | 방법 |
|---|---|
| 추가 | 입력창에 쓰고 Enter 또는 '추가' 버튼 |
| 마감일 지정 | 입력창 옆 날짜 버튼 |
| 완료 | 왼쪽 동그라미 클릭 |
| 수정 | 할 일 글자를 **더블클릭** |
| 중요 표시 | 오른쪽 별(★) 클릭 |
| 삭제 | 오른쪽 × 클릭 |
| 순서 변경 | 항목을 끌어서 이동 |
| 정렬 변경 | 오른쪽 위 정렬 버튼 클릭 (중요도순 → 마감일순 → 최신순 순환) |

마감일을 넣으면 D-Day가 표시되고 색으로 급한 정도를 알 수 있습니다.

- 빨강: 오늘 마감
- 주황: 3일 이내
- 파랑: 그 이후
- 회색: 기한이 지남

**완료 기록 보기**

오른쪽 위 **'기록'** 버튼을 누르면 완료한 할 일을 날짜 범위와 검색어로 찾아볼 수 있습니다.

### 급식 정보

- 오늘의 중식 메뉴와 칼로리를 보여줍니다.
- ◀ ▶ 버튼으로 어제·내일 등 다른 날짜를 확인할 수 있습니다.
- 학교에서 급식 정보를 등록하지 않은 날은 "중식 정보가 없습니다"로 표시됩니다.

### 학사일정

`[캡처 8] 학사일정 월간 뷰`

- **주간 / 월간** 버튼으로 보기를 바꿀 수 있습니다.
- ◀ ▶ 로 이전·다음 주(월)로 이동합니다.
- 월간 보기에서 날짜를 클릭하면 그날 일정이 팝업으로 뜹니다.
- 나이스에 등록된 학교 일정과, 설정에서 직접 추가한 일정이 함께 표시됩니다.

### 화면 위에 뜨는 것들

- **D-Day 뱃지**: 화면 상단 가운데. 등록한 D-Day 중 가까운 순으로 표시됩니다.
- **새 쪽지 알림**: 쪽지가 오면 알림이 뜨고, 누르면 쪽지함으로 이동합니다.
- **생일 축하 화면**: 생일 당일 접속하면 한 번 표시됩니다.

## 5. 쪽지함

`[캡처 7] 쪽지함`

같은 학교 선생님, 그리고 친구로 추가한 선생님과 메시지를 주고받는 공간입니다.

- **같은 학교 선생님은 자동으로 목록에 표시됩니다.** '새 대화'에서 선택해 바로 보낼 수 있습니다.
- 읽지 않은 메시지는 카카오톡처럼 숫자로 표시되고, 상대가 읽으면 사라집니다.
- 상대가 지금 대시보드를 켜두고 있으면 **접속 중**으로 표시됩니다.
- 상대의 현재 시간표 상태도 보입니다. (예: "수학 3교시", "점심시간", "오늘 수업 없음")

### 다른 학교 선생님 추가하기 (친구 코드)

1. 쪽지함 왼쪽 위에서 **내 친구 코드**를 확인합니다. (클릭하면 복사됩니다)
2. 상대에게 코드를 알려주고, 상대의 코드를 받습니다.
3. **친구 추가** 버튼 → 코드 입력 → 검색 → 추가.

친구는 목록에서 삭제할 수도 있습니다.

### 프로필 사진

쪽지함 왼쪽 위 사진을 눌러 이미지를 올릴 수 있습니다. 여기서 바꾼 사진은 대시보드의 쪽지함 버튼과 채팅창에도 함께 적용됩니다.

## 6. 화면 꾸미기

### 레이아웃 선택

**설정 → 화면 꾸미기 → 레이아웃**

- **가로 모니터**: 기본 4열 배치
- **세로 모니터**: 2열 하단 정렬 배치

가로와 세로의 위젯 배치는 **각각 따로 저장**됩니다.

### 위젯 배치 편집

`[캡처 2] 위젯 배치 편집 모드`

**설정 → 화면 꾸미기 → 레이아웃 → '편집 모드 열기'** 를 눌러 진입합니다. (대시보드에서 바로는 들어갈 수 없습니다)

편집 모드에서 할 수 있는 것:

| 동작 | 방법 |
|---|---|
| 위치 옮기기 | 위젯을 끌어서 이동 |
| 자리 바꾸기 | 다른 위젯 위로 끌면 서로 자리가 바뀜 |
| 크기 조절 | 위젯 가장자리나 모서리를 잡고 드래그 |
| 숨기기 | 위젯 오른쪽 위 ✕ |
| 다시 켜기 | 상단 툴바의 `+ 위젯이름` 버튼 |
| 처음 배치로 | 상단 툴바 '초기화' |

> 마지막에 **저장**을 눌러야 반영됩니다. '취소'를 누르면 변경사항이 사라집니다.

### 배경 설정

**설정 → 화면 꾸미기 → 배경 설정**

- **기본**: 회색 기본 배경
- **단색**: 프리셋 10가지 또는 직접 색상 선택
- **이미지**: 이미지 주소를 넣거나 파일을 업로드 (**5MB 이하**)

### 위젯 꾸미기

`[캡처 6] 설정 → 위젯 꾸미기`

위젯 카드의 모양을 바꿉니다. 오른쪽 미리보기로 바로 확인할 수 있습니다.

- 배경: 색상, 불투명도, 블러
- 테두리: 두께, 색상, 스타일
- 모서리 둥글기
- 그림자: 없음 / 작게 / 보통 / 크게 / 아주 크게
- 세부 색상: 퀵링크 바·글자, 할 일 입력창·글자, 시간표 헤더·오늘·빈칸

> 배경 이미지를 쓸 때는 위젯 불투명도를 낮추고 블러를 주면 배경이 비쳐 보여 예쁩니다.

### 시간표 오늘 하이라이트

**설정 → 레이아웃** 아래쪽 스위치로, 시간표에서 오늘 요일을 강조 표시할지 정합니다.

## 7. 그 밖의 설정

### D-Day 관리

**설정 → 학교·일정 → D-Day 관리**

아이콘, 일정 이름, 날짜를 등록하면 대시보드 상단에 D-Day가 표시됩니다. 여러 개 등록하면 날짜가 가까운 순으로 정렬됩니다.

### 학사일정 관리

**설정 → 학교·일정 → 학사일정 관리**

- 나이스에 없는 우리 학교 일정을 직접 추가할 수 있습니다. (시작일만 넣으면 하루짜리 일정)
- 오늘 일정의 배경색·글자색을 바꿀 수 있습니다.

### 주간 리포트

**설정 → 학교·일정 → 주간 리포트**

이번 주 완료한 할 일을 요일별 그래프로 보여줍니다. 총 완료 개수, 오늘 완료, 최고 기록, 일 평균을 함께 확인할 수 있습니다.

### 폴더 이름 / 퀵링크

**설정 → 기타**

- 폴더 위젯의 이름 3개를 변경합니다.
- 퀵링크는 **최대 7개**까지 추가할 수 있습니다. 4개를 넘으면 두 줄로 표시됩니다. (설정 버튼은 항상 마지막에 고정)

### 업데이트 내역

**설정 → 기타 → 업데이트 내역** 에서 새로 추가된 기능을 확인할 수 있습니다.

### 비밀번호 변경 / 회원 탈퇴

**설정 → 계정**

- 비밀번호는 6자 이상으로 변경할 수 있습니다.
- 회원 탈퇴는 확인란에 `탈퇴합니다` 를 입력해야 진행됩니다. 탈퇴하면 시간표, 할 일, 쪽지 등 모든 데이터가 삭제되며 되돌릴 수 없습니다.

## 8. 이럴 땐 이렇게

| 증상 | 해결 방법 |
|---|---|
| 급식·학사일정에 "학교 정보를 설정해주세요"만 보여요 | 설정 → 프로필 수정에서 교육청과 학교를 선택하세요 |
| 날씨가 "위치 권한이 필요합니다"로 나와요 | 브라우저(또는 배경화면 프로그램)에서 위치 접근을 허용하세요 |
| 급식이 "중식 정보가 없습니다"로 나와요 | 휴업일이거나 학교에서 아직 등록하지 않은 날입니다 |
| 시간표에 '학급 시간표' 탭이 없어요 | 설정 → 프로필 수정에서 담임 학급을 입력하세요 |
| 이번주에 바꾼 시간표가 사라졌어요 | 이번주 편집은 월요일에 자동 초기화됩니다. 계속 쓰려면 셀을 더블클릭해 원본을 수정하세요 |
| 위젯을 옮겼는데 다음에 오면 그대로예요 | 편집 모드에서 '저장'을 눌렀는지, 로그인 상태인지 확인하세요 |
| 교시 시간이 우리 학교와 달라요 | 설정 → 교시 시간에서 조정하세요 |
| 퇴근까지 남은 시간이 실제와 달라요 | 설정 → 교시 시간 → 기본 퇴근 시각을 확인하세요. 사용하지 않는 방과후 교시가 켜져 있어도 시각이 늘어납니다 |
| 로그인이 자꾸 풀려요 | 로그인 화면에서 '로그인 유지'를 켜세요 |
